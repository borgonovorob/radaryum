# Radaryum SEO Sprint 2 — Structured Data

Version: 6.2.0-structured-data

## Included
- Home JSON-LD graph: Organization, WebSite, WebPage and SoftwareApplication.
- `/companies`: CollectionPage, ItemList and BreadcrumbList.
- `/company/:slug`: Organization, CollectionPage, ItemList and BreadcrumbList.
- Visible breadcrumbs on the public company index and company pages.
- Dynamic canonical, robots, Open Graph and Twitter metadata.
- Related-company internal links retained.
- Public navigation links added to the home page and SEO footer.
- Google Search Console verification file retained.

## Deployment
Replace the repository contents with this package and deploy from `main`. No D1 migration or new secret is required.
